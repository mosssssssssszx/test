# การตรวจใบสั่งกับสูตร แต่ละค่ามาจากไหน

ระบบเอาของสองชุดมาประกบกัน

- **ใบสั่งผลิต** มาจากไฟล์ที่ SAP วางเข้ามา
- **สูตรการผลิต** มาจากข้อมูลที่ SAP ส่งเข้ามาทางออนไลน์

แล้วตอบว่าใบนี้ผลิตตามสูตรได้หรือไม่ ด้านล่างไล่ทีละค่าว่าตัวเลขนั้นหยิบมาจากไหน เอาไปเทียบกับอะไร และผลออกมาเพราะอะไร

โรงงานที่เปิดให้ตรวจตอนนี้มีแค่ **HHN** เปลี่ยนรายชื่อได้โดยไม่ต้องแก้โปรแกรม

## 1. ของทั้งสองชุด มีค่าอะไรบ้าง

```
ไฟล์ใบสั่ง                              สูตรที่ส่งออนไลน์
─────────────────────────              ─────────────────────────
เลขใบสั่ง                               รหัสสินค้า
รหัสสินค้าที่จะผลิต                     รหัสกระบวนการ
ขนาดล็อต                                โรงงาน
หน่วยของล็อต                            ล็อตต่ำสุด
รหัสกระบวนการ                          ล็อตสูงสุด
  (อยู่ในรายการวัตถุดิบ แถวแรกที่มีค่า)

รายการวัตถุดิบ แต่ละตัว                 ขั้นตอนการผลิต แต่ละขั้น
  รหัสวัตถุดิบ                            รหัสที่ใช้ได้ในขั้นนี้
  ปริมาณ                                  เปอร์เซ็นต์ของล็อต
  หน่วย                                   เป็นขั้นปรับแต่งหน้างานหรือไม่
```

ค่าที่ **ไม่ได้** เอามาตัดสิน

- รหัสโรงงานในไฟล์ใบสั่ง เช่น `30` ระบบไม่ใช้
- ชื่อขั้นตอนที่ไม่ใช่การใส่วัตถุดิบ เช่น ให้ความร้อน ผสม ตรวจค่า เก็บไว้เฉย ๆ ไม่มีผลต่อผ่านหรือไม่ผ่าน

## 2. ภาพการเทียบ ทีละเรื่อง

ระบบทำจากบนลงล่าง เจอเรื่องที่ไม่ผ่านก็หยุด ไม่ไปเรื่องถัดไป

```
เรื่องที่ 1  จับคู่ให้ได้ก่อน
            รหัสสินค้าในใบสั่ง          เทียบกับ    รหัสสินค้าในสูตร
            รหัสกระบวนการในใบสั่ง       เทียบกับ    รหัสกระบวนการในสูตร
            จับไม่ได้  →  ไม่มีผลตรวจ  (ไม่ใช่ไม่ผ่าน)

เรื่องที่ 2  โรงงาน
            โรงงานในสูตร                เทียบกับ    รายชื่อโรงงานที่อนุญาต (ตอนนี้ HHN)
            ไม่มีในรายชื่อ  →  ไม่ผ่าน   ข้อความ Plant HH is not allowed.

เรื่องที่ 3  ขนาดล็อต
            ขนาดล็อตในใบสั่ง            เทียบกับ    ล็อตต่ำสุด และล็อตสูงสุดในสูตร
            อยู่นอกช่วง  →  ไม่ผ่าน

เรื่องที่ 4  รหัสวัตถุดิบ
            รหัสในใบสั่ง                เทียบกับ    รหัสที่ใช้ได้ในทุกขั้นตอนของสูตร
            ใบสั่งมีตัวที่สูตรไม่มี  →  ไม่ผ่าน   ข้อความ Order code not in recipe

เรื่องที่ 5  ปริมาณ
            ของในใบสั่ง                 เทียบกับ    ขนาดล็อต × เปอร์เซ็นต์ ÷ 100
            ขาดหรือเกิน  →  ไม่ผ่าน
            ตรงทุกตัว  →  ผ่าน และล็อกผล
```

## 3. แต่ละค่ามาจากไหน แล้วกลายเป็นอะไร

| ค่าที่เห็นในผลตรวจ | มาจากไหน | ระบบเอาไปทำอะไร |
|---|---|---|
| เลขใบสั่ง | ไฟล์ใบสั่ง | เอาไว้ชี้ว่าผลนี้เป็นของใบไหน |
| รหัสสินค้า | ไฟล์ใบสั่ง ช่องสินค้าที่จะผลิต | ไปหาสูตรที่รหัสสินค้าเดียวกัน |
| รหัสกระบวนการ | ไฟล์ใบสั่ง ในรายการวัตถุดิบ **แถวแรกที่มีรหัสกระบวนการ** | ไปหาสูตรที่กระบวนการเดียวกัน |
| ขนาดล็อต | ไฟล์ใบสั่ง ช่องปริมาณที่จะผลิต | ใช้คูณเปอร์เซ็นต์ และเช็กว่าอยู่ในช่วงของสูตร |
| หน่วยของล็อต | ไฟล์ใบสั่ง เช่น KG | หน่วยที่ใช้คิดทั้งใบ |
| โรงงาน | **สูตร** ไม่ใช่ไฟล์ใบสั่ง | เช็กว่าอยู่ในรายชื่อที่อนุญาตหรือไม่ |
| ล็อตต่ำสุด / ล็อตสูงสุด | สูตร | เช็กขนาดล็อตของใบสั่ง |
| รหัสที่ใช้ได้ในขั้นตอน | สูตร ถ้าเขียน `120226\|120246\|120247` แปลว่าสามตัวนี้ใช้แทนกันได้ เลือกได้ตัวเดียว | เอาไปหาของในใบสั่ง |
| เปอร์เซ็นต์ | สูตร ของขั้นตอนนั้น | เอาไปคูณขนาดล็อต |
| ปริมาณวัตถุดิบในใบสั่ง | ไฟล์ใบสั่ง รวมทุกบรรทัดที่เป็นรหัสเดียวกัน ถ้าส่งไฟล์เลขใบสั่งเดิมเข้าซ้ำ ตัวเลขจะถูกบวกเพิ่ม | เอาไปลบกับปริมาณที่สูตรต้องการ |
| ปริมาณที่สูตรต้องการ | **ไม่ได้มาจากไฟล์** คำนวณจากขนาดล็อตกับเปอร์เซ็นต์ | เอาไปเทียบกับของในใบสั่ง |
| ส่วนต่าง | **คำนวณ** ของในใบสั่ง ลบ ของที่สูตรต้องการ | ตัดสินว่าตรง ขาด หรือเกิน |
| ข้อความผลตรวจ | ระบบสร้างจากเรื่องแรกที่ไม่ผ่าน | เป็นคำตอบของใบนั้น |

## 4. สูตรปริมาณ ตัวเลขแต่ละตัวมาจากไหน

```
ขนาดล็อต          มาจากไฟล์ใบสั่ง
เปอร์เซ็นต์       มาจากขั้นตอนในสูตร
                         │
                         ▼
              ปริมาณที่ต้องใช้  =  ขนาดล็อต  ×  เปอร์เซ็นต์  ÷  100
                         │
ของในใบสั่ง       มาจากไฟล์ใบสั่ง รวมปริมาณของรหัสนั้น
                         │
                         ▼
              ส่วนต่าง  =  ของในใบสั่ง  −  ปริมาณที่ต้องใช้
```

วิธีอ่านส่วนต่าง

| ส่วนต่าง | แปลว่า |
|---|---|
| ไม่เกิน 1 กรัม ทั้งบวกและลบ (0.001 กิโลกรัม) | ตรง |
| ติดลบมากกว่านั้น | ขาด ของในใบสั่งน้อยกว่าที่สูตรต้องการ |
| เป็นบวกมากกว่านั้น | เกิน ของในใบสั่งมากกว่าที่สูตรต้องการ |

กรัมกับกิโลกรัมถูกแปลงก่อนเทียบ

```
กรัม ÷ 1,000 = กิโลกรัม
กิโลกรัม × 1,000 = กรัม     (แปลงกลับตอนแสดงผล)
```

ขั้นที่สูตรบอกว่าเป็นการปรับแต่งหน้างาน ไม่มีเปอร์เซ็นต์ ระบบตรวจแค่รหัสนั้นมีในใบสั่ง ไม่คิดส่วนต่าง

ถ้ารหัสหนึ่งถูกใช้หลายขั้นตอน ต้องบวก "ปริมาณที่ต้องใช้" ของทุกขั้นนั้นก่อน แล้วค่อยลบกับของในใบสั่งครั้งเดียว

## 6. ใบที่ไม่ผ่าน อ่านแบบเดียวกัน ว่าหยุดตรงค่าไหน

### โรงงานไม่ได้รับอนุญาต — TEST-HH-01

| ค่า | ตัวเลข | มาจาก | เอาไปเทียบกับ |
|---|---|---|---|
| รหัสสินค้า | 206.0202 | ไฟล์ใบสั่ง | รหัสสินค้าในสูตร ตรงกัน จึงจับสูตรได้ |
| รหัสกระบวนการ | D-PC-2060202-A-05 | ไฟล์ใบสั่ง | กระบวนการในสูตร ตรงกัน |
| โรงงาน | HH | **สูตร** | รายชื่อที่อนุญาต มีแค่ HHN |

HH ไม่มีในรายชื่อ หยุดตรงนี้ ยังไม่เอาขนาดล็อตไปคูณเปอร์เซ็นต์

ผลคือไม่ผ่าน ข้อความ `Plant HH is not allowed.`

ขนาดล็อต 100 กิโลกรัม มาจากไฟล์ใบสั่งนี้เช่นกัน ถ้าโรงงาน HH ถูกเปิดให้ตรวจ ขั้นต่อไปจะเอา 100 ไปเทียบกับล็อตต่ำสุดของสูตรซึ่งคือ 3,500 แล้วไม่ผ่านเพราะล็อตเล็กเกินไป แต่ตอนนี้ยังไม่ถึงขั้นนั้น

### ปริมาณเกินเพราะส่งไฟล์ซ้ำ — 80000001

สูตรต้องการ 101003 เท่ากับใบที่ผ่าน

```
209 กก. = 10,000 × 2.09 ÷ 100
         ขนาดล็อตมาจากไฟล์    เปอร์เซ็นต์มาจากสูตร
```

ของในใบสั่งไม่ได้มาจากไฟล์เดียว

```
209 กก.   มาจากไฟล์วันที่ 13 สิงหาคม
209 กก.   มาจากไฟล์วันที่ 5 ตุลาคม
─────
418 กก.   ระบบรวมของเลขใบสั่งเดียวกัน

ส่วนต่าง = 418 − 209 = เกิน 209 กก.
```

วัตถุดิบอีกแปดตัวเกินเป็นสองเท่าด้วยเหตุเดียวกัน ผลคือปริมาณไม่ตรงเก้าตัว สูตรไม่ได้เปลี่ยน ตัวเลขฝั่งใบสั่งถูกบวกเพราะส่งไฟล์เข้าสองครั้ง

## 7. ทำไมผลที่เคยผ่าน กลายเป็นไม่ผ่าน

วันที่ 12 ตุลาคม 2569 เวลา 13:53 น. ไฟล์ใบสั่งชุดเดิมถูกส่งเข้าอีกครั้ง

ค่าที่เปลี่ยนมีอย่างเดียว คือ **ของในใบสั่ง** เพราะระบบรวมปริมาณของเลขใบสั่งเดียวกันทุกครั้งที่ไฟล์เข้า

ค่าที่ไม่เปลี่ยน คือ ขนาดล็อตในหัวใบสั่ง, เปอร์เซ็นต์ในสูตร, โรงงาน, ช่วงล็อตที่สูตรรับได้

ใบสั่ง 80000003 เดิมมีส่วนต่างเป็นศูนย์ทุกตัว พอของในใบสั่งถูกบวกอีกหนึ่งชุด ส่วนต่างกลายเป็นบวกเท่ากับปริมาณที่สูตรต้องการ ทั้งใบจึงไม่ผ่านเรื่องปริมาณ

ผลเก่าไม่ได้ถูกลบ แค่ไม่ใช่ผลปัจจุบัน ผลปัจจุบันใช้ของในใบสั่งหลังบวกแล้ว

คู่ใบสั่งกับสูตรที่ตรวจไปแล้ว จะไม่ถูกคิดใหม่เอง แม้จะเปลี่ยนรายชื่อโรงงานทีหลัง ต้องลบผลเดิมก่อนจึงจะตรวจใหม่
